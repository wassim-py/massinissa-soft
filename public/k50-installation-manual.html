Massinissa School Software (Online Cloud Deployment) • Branches: ECOLE, ANNEX, AMPHI

Can One Branch Use Direct Cable and Another Use the Router?
YES, 100% ABSOLUTELY! Each branch's PC runs its own local bridge. One branch can have the K50 Pro plugged straight into the PC via Ethernet, while another branch has the K50 Pro plugged into the building router or switch. Both work simultaneously and sync seamlessly with the online cloud application.
Option A: Direct Cable to PC

Best when the reader is placed right on the reception desk next to the computer.

  • K50 Pro plugged into PC Ethernet port
  • PC connects to Internet via Wi-Fi
  • PC Ethernet IPv4 set to static 192.168.50.1 (Gateway empty)
  • K50 Pro IP: 192.168.50.201
  • Installer: Press [Enter] for default
Option B: Plugged into Router / Switch

Best when the reader is mounted on a wall or hallway near the entrance.

  • K50 Pro plugged into Router LAN port or wall jack
  • PC connects to same router (Wi-Fi or cable)
  • PC keeps standard automatic IP (DHCP)
  • K50 Pro IP: matching router, e.g. 192.168.1.201
  • Installer: Enter 192.168.1.201

1. Option A Setup (Direct RJ45 Cable to PC)

  1. On K50 Pro: Hold M/OK → Comm. → Ethernet: Set IP to 192.168.50.201, Netmask 255.255.255.0, Gateway 0.0.0.0, Port 4370, DHCP OFF.
  2. On Windows PC: Press Win + R → ncpa.cpl → Properties of Ethernet → IPv4 → Set IP to 192.168.50.1, Netmask 255.255.255.0, leave Default Gateway blank.
  3. Run Installer: Right-click INSTALLER_ET_DEMARRER_PONT_K50.bat → Run as administrator → Press [Enter].

2. Option B Setup (K50 Pro Plugged into Router)

  1. Find Router Range: Open PowerShell on the PC and run Get-NetRoute -DestinationPrefix '0.0.0.0/0' to see your router gateway (usually 192.168.1.1 or 192.168.0.1).
  2. On K50 Pro: Hold M/OK → Comm. → Ethernet:
    • IP Address: Choose an unused IP, e.g. 192.168.1.201
    • Subnet Mask: 255.255.255.0
    • Gateway: Your router IP (e.g. 192.168.1.1)
    • Port: 4370, DHCP: OFF
  3. On Windows PC: No special IP configuration needed! Both the PC and K50 Pro are connected to the same router.
  4. Test Connection: In PowerShell, run Test-NetConnection 192.168.1.201 -Port 4370 → verify TcpTestSucceeded : True.
  5. Run Installer: Right-click INSTALLER_ET_DEMARRER_PONT_K50.bat → Run as administrator → Type 192.168.1.201 and press [Enter].

3. Daily Usage & Key Benefits

  • Sub-200ms Scans: Scans stream instantly from K50 Pro → local bridge → browser in 0ms, updating attendance and remaining credits immediately.
  • Strict Branch Isolation: Scans at AMPHI only evaluate AMPHI lessons. If an ECOLE student visits AMPHI, the Catch-Up (Rattrapage) card opens so they can be logged into a catch-up group without altering their original group.
  • Anti-Inactivity Keepalive (v3): An active 8-second protocol heartbeat keeps the K50 Pro session alive 24/7 without timing out or sleeping.
  • Instant Reconnect: If a router or K50 Pro reboots, toggle the Fingerprint button in the top navbar OFF then ON for an immediate re-handshake in < 50ms.
