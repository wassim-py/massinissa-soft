ZKTeco K50 Pro — Installation & User Manual v3 Self-Healing

Massinissa School Software (Online Cloud Deployment) • Branches: ECOLE, ANNEX, AMPHI

1. Overview & Architecture

Because the Massinissa School Software is deployed online in the cloud, the physical ZKTeco K50 Pro reader (connected by a direct RJ45 Ethernet cable to the School PC) cannot be reached across the public internet without a local bridge.

To bridge this connection seamlessly, the School PC runs a lightweight background service (zk-bridge):

  • Physical Link: Communicates with the K50 Pro over Ethernet (192.168.50.201:4370).
  • Instant Browser Link (SSE): Streams scans directly to the web app in < 2ms via Server-Sent Events (http://127.0.0.1:4375/events).
  • Zero Cloud Polling Quota: Eliminates continuous database polling, cutting NeonDB query consumption by over 75%.
  • Self-Healing Engine (v3): Sends an active 8-second ZKTeco application heartbeat (CMD_REG_EVENT) that prevents the K50 Pro session from ever expiring and keeps the PC's Ethernet card awake 24/7. If the cable is unplugged or the device rebooted, it auto-reconnects within 2–3 seconds.

2. Prerequisites on Each School PC

  1. Wi-Fi Internet Connection: Ensure the School PC connects to the internet via Wi-Fi so the Ethernet (RJ45) port remains free exclusively for the ZKTeco K50 Pro.
  2. Node.js Installed: Install Node.js LTS from https://nodejs.org if not already installed.
  3. Copy the zk-bridge Folder: Copy the zk-bridge folder from the project onto the School PC (contains zk-bridge.js, INSTALLER_ET_DEMARRER_PONT_K50.bat, and ARRETER_PONT_K50.bat).

3. Step 1 — Configure the ZKTeco K50 Pro Hardware

Hold the M/OK key on the K50 Pro for 2 seconds to open the menu, then select Comm. → Ethernet:

B. Multiple Readers on the Same PC (via 5-Port Ethernet Switch)

Connect the PC and all K50 Pro readers to an Ethernet switch with RJ45 cables and assign a unique IP to each reader:

  • Reader #1: 192.168.50.201 (Subnet 255.255.255.0, Port 4370, DHCP OFF)
  • Reader #2: 192.168.50.202 (Subnet 255.255.255.0, Port 4370, DHCP OFF)
  • Reader #3: 192.168.50.203 (Subnet 255.255.255.0, Port 4370, DHCP OFF)

4. Step 2 — Configure the Windows PC Ethernet Adapter (Static IP 192.168.50.1)

  1. Press Win + R, type ncpa.cpl, and press Enter.
  2. Right-click on Ethernet (wired adapter connected to the K50 Pro) → click Properties.
  3. Double-click on Internet Protocol Version 4 (TCP/IPv4).
  4. Select Use the following IP address and enter:
    • IP address: 192.168.50.1
    • Subnet mask: 255.255.255.0
    • Default gateway: LEAVE COMPLETELY BLANK!
  5. Click OK, then OK again.
Crucial: Always leave the Default Gateway blank on the Ethernet adapter. This guarantees Windows uses Wi-Fi for all internet traffic while routing 192.168.50.x exclusively over the Ethernet cable.

To verify the hardware connection, open PowerShell and run:

Test-NetConnection 192.168.50.201 -Port 4370

Confirm that the output shows TcpTestSucceeded : True.

5. Step 3 — Run the 1-Click Local Bridge Installer (zk-bridge)

  1. Open the zk-bridge folder on the School PC.
  2. Right-click on INSTALLER_ET_DEMARRER_PONT_K50.bat and click Run as administrator.
  3. Press [Enter] to keep the default IP 192.168.50.201 (or enter 192.168.50.201,192.168.50.202 for multiple readers).
What the v3 1-Click Installer Does Automatically:
  • Copies zk-bridge.js to %USERPROFILE%\MassinissaK50Bridge\
  • Disables Ethernet Power Saving: Turns off Windows PowerSavingMode, Green Ethernet, and Energy-Efficient Ethernet (EEE) on the Ethernet card so it never enters idle sleep
  • Opens ports 4370 and 4375 in Windows Firewall
  • Installs a silent auto-startup launcher in Windows Startup (shell:startup) so it starts invisibly every morning when the PC turns on (no black console window)
  • Starts the v3 self-healing bridge immediately on http://127.0.0.1:4375

6. Step 4 — Open the Online Application

  1. Open your online Massinissa School Software URL in Chrome or Edge.
  2. Select the PC's branch in the top navigation bar (ECOLE, ANNEX, or AMPHI).
  3. Ensure the Fingerprint button in the top bar is toggled ON.
  4. If Chrome asks for permission to "Look for and connect to any device on your local network", click Allow.
  5. The status dot on the Fingerprint ON button will immediately turn Green (Connected)!

7. Daily Operation & Advanced Features

  • Sub-200ms Scans: Finger scans are streamed to the browser via local SSE in 0ms, updating the attendance roster and remaining credits instantly without waiting for cloud polling.
  • Strict Branch Isolation: Scanning at AMPHI only checks AMPHI lessons. If a student enrolled at ECOLE attends AMPHI, the Catch-Up (Rattrapage) card appears on screen to log their attendance safely.
  • Zero Duplicates: Repeated scans during the same lesson do not create duplicate attendance records or deduct extra credits.
  • Anti-Inactivity Heartbeat (v3): The bridge pings the K50 Pro every 8 seconds over Ethernet, keeping the session alive all day even when idle.
  • Manual Instant Reconnect: If the device was ever unplugged or restarted, toggling the Fingerprint button in the top navbar OFF then ON forces an instant hardware re-handshake in < 50ms.

8. Troubleshooting Checklist

Issue Cause Solution
Wi-Fi internet disconnects when Ethernet cable is plugged in A Default Gateway was entered in Ethernet IPv4 properties Open ncpa.cpl → Ethernet → IPv4 and clear the Default Gateway field.
Fingerprint button stays Red/Offline in the online app Local Bridge not running or Chrome blocked local network access Run INSTALLER_ET_DEMARRER_PONT_K50.bat as administrator and allow Local network access in Chrome site permissions.
`TcpTestSucceeded : False` on `192.168.50.201` Cable unplugged or PC Ethernet IP lost Verify cable connection and run ipconfig in PowerShell to verify Ethernet has IPv4 192.168.50.1.
Device was unplugged, restarted, or idle overnight Session dropped or cable reconnected The v3 bridge auto-reconnects in 2–3 seconds. You can also toggle the Fingerprint button in the top navbar OFF then ON to force an immediate reconnect.
Ethernet port sleeps after long inactivity Realtek Power Saving / Green Ethernet enabled Run INSTALLER_ET_DEMARRER_PONT_K50.bat to disable power saving, or open Device Manager (devmgmt.msc) → Realtek Controller → Advanced → set Energy-Efficient Ethernet, Green Ethernet, and Power Saving Mode to Disabled.
Student scans finger but sees "Out of Slot / Catch-Up" Wrong branch selected in the top navbar Ensure the branch selected in the top bar matches the physical building (ECOLE, ANNEX, or AMPHI).
How to stop the background bridge service Need to stop background Node.js bridge Double-click ARRETER_PONT_K50.bat in the zk-bridge folder.
