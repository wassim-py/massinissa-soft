ZKTeco K50 Pro — School PC Installation Manual

Massinissa School Software (Online Cloud Deployment) • Branches: ECOLE, ANNEX, AMPHI

1. Prerequisites on Each School PC

  1. Wi-Fi Internet Connection: Ensure the School PC connects to the internet via Wi-Fi so the Ethernet (RJ45) port stays dedicated to the ZKTeco K50 Pro.
  2. Node.js Installed: Install Node.js LTS from https://nodejs.org if not already installed.
  3. Copy the zk-bridge Folder: Copy the zk-bridge folder from the project onto the School PC (contains zk-bridge.js, INSTALLER_ET_DEMARRER_PONT_K50.bat, and ARRETER_PONT_K50.bat).

2. Step 1 — Configure the ZKTeco K50 Pro Hardware

Hold the M/OK key on the K50 Pro for 2 seconds to open the menu, then select Comm. → Ethernet:

A. Single Reader on the PC (Direct Ethernet Cable to PC)

K50 Pro Setting Value to Enter
IP Address192.168.50.201
Subnet Mask255.255.255.0
Gateway0.0.0.0 (or 192.168.50.1)
TCP Port4370
DHCPOFF (Disabled)
Comm Key (Password)0

B. Multiple Readers on the Same PC (via 5-Port Ethernet Switch)

Connect the PC and all K50 Pro readers to an Ethernet switch with RJ45 cables and assign a unique IP to each reader:

  • Reader #1: 192.168.50.201 (Subnet 255.255.255.0, Port 4370, DHCP OFF)
  • Reader #2: 192.168.50.202 (Subnet 255.255.255.0, Port 4370, DHCP OFF)
  • Reader #3: 192.168.50.203 (Subnet 255.255.255.0, Port 4370, DHCP OFF)

3. Step 2 — Configure the Windows PC Ethernet Port

  1. Press Win + R, type ncpa.cpl, and press Enter.
  2. Right-click on Ethernet (wired adapter connected to the K50 Pro) → click Properties.
  3. Double-click on Internet Protocol Version 4 (TCP/IPv4).
  4. Select Use the following IP address and enter:
    • IP address: 192.168.50.1
    • Subnet mask: 255.255.255.0
    • Default gateway: LEAVE COMPLETELY BLANK!
  5. Click OK, then OK.
Important: Always leave the Default Gateway blank on the Ethernet adapter. This guarantees Windows keeps using Wi-Fi for internet while routing 192.168.50.x over the Ethernet cable.

To verify the hardware connection, open PowerShell and run:

Test-NetConnection 192.168.50.201 -Port 4370

Confirm that the output shows TcpTestSucceeded : True.

4. Step 3 — Run the 1-Click Local Bridge Installer (zk-bridge)

Because the application is hosted online, the School PC runs a tiny local service (zk-bridge) that streams finger scans to the browser in < 2 milliseconds:

  1. Open the zk-bridge folder on the School PC.
  2. Right-click on INSTALLER_ET_DEMARRER_PONT_K50.bat and click Run as administrator.
  3. Press [Enter] to keep the default IP 192.168.50.201 (or type 192.168.50.201,192.168.50.202 if you have 2 readers on this PC).
What the 1-Click Installer Does Automatically:
  • Copies zk-bridge.js to %USERPROFILE%\MassinissaK50Bridge\
  • Opens ports 4370 and 4375 in Windows Firewall
  • Installs a silent auto-startup launcher in Windows Startup (shell:startup) so it starts invisibly every morning when the PC turns on
  • Starts the bridge immediately on http://127.0.0.1:4375

5. Step 4 — Open the Online Application

  1. Open your online Massinissa School Software URL in Chrome or Edge.
  2. Select the PC's branch in the top navigation bar (ECOLE, ANNEX, or AMPHI).
  3. Ensure the Fingerprint button in the top bar is toggled ON.
  4. If Chrome asks for permission to "Look for and connect to any device on your local network", click Allow.
  5. The status dot on the Fingerprint ON button will immediately turn Green (Connected)!

6. Troubleshooting Checklist

Issue Cause Solution
Wi-Fi internet disconnects when Ethernet cable is plugged in A Default Gateway was entered in the Ethernet IPv4 properties Open ncpa.cpl → Ethernet → IPv4 and clear the Default Gateway field.
Fingerprint button stays Red/Offline in the online app Local Bridge not started or Chrome blocked local network access Run INSTALLER_ET_DEMARRER_PONT_K50.bat once and allow Local network access in Chrome site permissions.
Student scans finger at AMPHI and sees Catch-Up card Normal if their scheduled group is at ECOLE (or wrong branch selected in navbar) Verify the active branch in the top bar matches the physical building (ECOLE, ANNEX, or AMPHI).
